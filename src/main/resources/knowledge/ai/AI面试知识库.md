# AI 岗位 RAG 黄金知识库与面试题库精选（30 题）

## 模块一：机器学习基础

### 1. 偏差-方差权衡
过拟合与欠拟合的核心本质是模型的偏差与方差权衡。偏差衡量模型预测与真实值之间的系统性偏离，通常反映模型表达能力不足并导致欠拟合；方差衡量训练样本变化引起的预测波动，反映模型对样本噪声的敏感程度，方差过高通常导致过拟合。对平方误差等设定，总泛化误差可分解为偏差平方、方差与不可约减误差。降低训练误差不一定改善泛化，应使用独立验证集评估模型在未见样本上的表现。

### 2. L1 与 L2 正则化
L1 正则化把权重绝对值之和加入损失函数，常使部分权重精确变为零，因此可产生稀疏解并具有特征选择效果。L2 正则化把权重平方和加入损失，倾向于连续缩小权重而非将其置零，有助于限制参数幅度和降低方差。正则化强度需要通过验证数据选择；L1、L2 对相关特征的处理不同，不能简单认为任一种总是更优。

### 3. 分类指标与类别不平衡
精确率是预测为正的样本中实际为正的比例，召回率是实际为正的样本中被检出的比例。类别严重不平衡时，Accuracy 可能被多数类主导而显得很高，因此应结合任务代价选择指标。ROC-AUC 衡量正样本得分高于负样本的排序能力；当正类稀少且更关心正类检出时，PR 曲线及 PR-AUC 通常更能揭示误报和漏报之间的取舍。阈值应基于验证集和实际业务成本确定。

## 模块二：深度学习与 Transformer

### 4. Transformer 自注意力与缩放
缩放点积注意力为 Attention(Q,K,V) = softmax(QK^T / sqrt(d_k))V。若 Q、K 的各维度近似独立且方差相近，点积方差会随维度 d_k 增长；除以 sqrt(d_k) 可以控制 logits 的尺度，降低 softmax 进入过度饱和区的风险，从而使梯度训练更稳定。注意力通过查询与键的相似度计算权重，再对值向量加权汇总。

### 5. 多头注意力的设计动机
多头注意力将 Q、K、V 分别投影到多个表示子空间，在各子空间并行计算注意力，再拼接并投影结果。多个头使模型能够在不同表示子空间学习不同的关系模式，而不是依赖单一注意力分布。不能把某个头固定解释为语法头或语义头；头的具体功能取决于训练过程与模型，通常需要分析而不能预先保证。

### 6. LayerNorm 与 BatchNorm
BatchNorm 通常沿批次维度统计每个特征的均值和方差，训练时依赖批次统计量，推理时使用运行统计量。LayerNorm 在单个样本的特征维度上归一化，不依赖同批其他样本，因此适用于变长序列和批次较小的场景。Transformer 常使用 LayerNorm，也有架构使用 RMSNorm；选择取决于模型设计，Padding 处理仍需通过掩码等机制正确完成。

## 模块三：大语言模型与对齐

### 7. 预训练、指令微调与偏好对齐
自回归预训练通常通过预测下一个 Token 学习语言统计规律和表示能力。监督指令微调使用指令与示例回答训练模型，使其更好地遵循任务格式。偏好对齐阶段可利用人类偏好数据改善回答行为，例如 RLHF 训练奖励模型并使用强化学习优化策略，或使用 DPO 直接基于偏好对优化策略。不同系统的训练流程并不完全相同，对齐也不能保证事实永远正确或彻底消除有害输出。

### 8. DPO 与 PPO 式 RLHF
典型 RLHF 流程先以偏好数据训练奖励模型，再使用 PPO 等方法优化策略，涉及奖励估计、策略约束和生成采样，工程组件较多。DPO 从特定的偏好优化目标推导出可直接训练策略模型的分类式损失，避免在优化环节显式训练并调用独立奖励模型和完整 PPO 在线循环。DPO 仍需要高质量偏好数据、参考策略及合理超参数；它不意味着无需数据或在所有任务上都优于 PPO。

## 模块四：分词、长上下文与推理

### 9. BPE 子词分词
Byte Pair Encoding 起初把文本表示为字符或字节序列，再反复合并语料中频率较高的相邻符号对，形成受限词表的子词单元。子词词表在词汇复用和序列长度之间折中，并可组合表示未见过的词。实际 Tokenizer 的具体算法与预处理因模型而异；Token 数不等同于字符数，尤其在不同语言、代码和特殊符号中差异明显。

### 10. RoPE 旋转位置编码
RoPE 将查询和键向量的维度对按位置进行旋转变换，使注意力点积包含相对位置差的信息。该机制将绝对位置对应的旋转作用结合进 Q、K，而相对位置关系体现在二者的内积中。RoPE 被多种 Transformer 模型采用，但长上下文外推能力还受训练长度、频率缩放方式和模型其他组件影响，单独使用 RoPE 不保证任意长度都能保持质量。

### 11. KV Cache 与解码成本
自回归生成时，模型每一步需要基于历史 Token 计算注意力。KV Cache 保存先前 Token 各层的 Key 和 Value，避免后续步骤重复计算这些表示，降低逐 Token 解码中的重复计算。代价是缓存随层数、上下文长度、批次和隐藏维度增长，占用显存；它不会让整个生成过程的所有计算都变成常数，也不是消除长上下文注意力成本的通用方案。

### 12. FlashAttention
FlashAttention 是一种 IO 感知的精确注意力算法，通过分块计算和在线 softmax 等技术减少 QK 与注意力矩阵在 GPU 高带宽显存和片上 SRAM 之间的读写。它避免显式物化完整注意力矩阵，从而降低长序列下的内存占用并改善实际运行速度。它不是近似注意力；实际收益取决于硬件、序列长度、数据类型和实现版本。

## 模块五：Embedding 与向量检索

### 13. 稠密检索与 BM25
BM25 是基于词项匹配、词频和逆文档频率的稀疏检索方法，擅长精确术语、标识符和罕见关键词匹配。稠密检索通过编码器将查询和文档映射为向量，再按相似度检索，对语义改写和同义表达通常更有优势，但可能错过精确术语或受领域差异影响。混合检索可融合两类结果，例如使用 Reciprocal Rank Fusion；应以领域数据评估而不是假设某种方法总是更优。

### 14. 余弦相似度与内积
余弦相似度是向量点积除以两个向量的模长，主要比较方向；内积还会受向量长度影响。若两个向量都经过 L2 归一化，则点积等于余弦相似度。检索服务必须确认 Embedding 模型的归一化约定、距离度量和索引配置一致，否则排序语义可能不同。数值相近也不自动代表文本事实相关，需要用标注查询评测检索质量。

### 15. HNSW 近似最近邻索引
HNSW 通过多层邻近图实现近似最近邻搜索：上层图较稀疏，可用于快速跨区域导航，底层包含更多节点以细化搜索。查询从高层开始逐步向更近邻节点移动。构建参数、搜索宽度和数据分布会影响内存占用、查询延迟及召回率，因此需在目标数据集上权衡。HNSW 是近似搜索结构，不保证每次都返回数学意义上的精确最近邻。

## 模块六：RAG 架构与评估

### 16. 检索增强生成的基本流程
RAG 在生成回答前从外部知识库检索相关片段，再将查询与片段组成上下文交给语言模型。它可让回答使用可更新的外部资料，并帮助提供引用依据；但效果依赖知识覆盖、检索质量、上下文组织和模型是否忠实使用证据。RAG 不会自动消除幻觉，也不自动保证文档权限隔离，系统需要设计访问控制、来源追踪和拒答策略。

### 17. Chunk 切分粒度与重叠
Chunk 过大可能混入无关内容并降低检索定位精度，过小则可能切断定义、条件和结论之间的语义关系。可从段落、标题、句子或固定长度切分开始，通过人工审核的查询集对比不同策略。重叠窗口有助于保留边界上下文，但会增加索引规模和重复检索。不存在对所有语料都最优的固定字符数或重叠比例，应根据语料结构、Embedding 模型和检索指标调整。

### 18. 召回与重排的级联架构
向量召回阶段通常使用双塔 Embedding 独立编码查询和文档，能够高效从较大语料中筛选候选，但查询与文档之间的细粒度交互有限。重排阶段可用 Cross-Encoder 联合编码查询与候选文本，对少量候选进行更精细的相关性判断，代价是逐候选计算更昂贵。整体质量受候选召回上限约束：相关文档未进入候选集时，重排无法将其找回。

### 19. RAG 检索与生成评估
RAG 评估应区分检索和答案生成。检索侧可使用 Recall@K、MRR、nDCG 或上下文精确率，检查相关证据是否被召回及排序位置；生成侧可评估答案相关性和忠实度，即答案是否切题、是否有检索证据支持。自动化模型评分能扩展评测规模，但应使用人工抽检、明确评分规程和固定数据集校准，避免把单个综合分数误认为真实质量。

## 模块七：提示词注入与安全

### 20. 直接与间接提示词注入
直接提示词注入是用户在输入中试图改变模型行为或覆盖任务指令。间接提示词注入则把恶意指令藏在网页、文件或检索文档中，由应用将其作为上下文交给模型。模型可能难以可靠地区分可信指令和不可信数据，因此不能仅依赖提示词要求模型忽略攻击。应使用最小权限工具、对工具参数进行服务端校验、隔离不可信内容，并对敏感操作设置授权和确认。

### 21. LLM 应用的纵深防御
OWASP LLM 应用风险涵盖提示词注入、敏感信息泄露、过度授权等类别。防御应分层实施：限制模型可调用的工具和数据范围；在服务端验证身份、权限和参数；将检索内容视为不可信数据；对输出和工具副作用设置策略检查、审计及必要的人类确认。输入过滤或 XML 标签可以改善结构，但不是安全边界，关键权限控制必须由模型之外的应用代码落实。

## 模块八：Agent 与工具调用

### 22. ReAct 推理与行动循环
ReAct 将语言模型推理与外部行动结合：模型提出行动，环境或工具返回观察结果，模型再基于结果继续处理。它适合需要动态信息或多步工具交互的任务，但工具错误、无效计划和循环调用都可能造成失败或成本上升。生产实现应限制工具集合、参数、步数和超时，并根据工具返回的可验证结果决定是否继续，而不是无限执行模型计划。

### 23. Function Calling 的执行边界
Function Calling 通常由应用向模型提供工具名称、描述和参数 schema，模型输出结构化调用意图；模型本身并不因此获得宿主机执行权限。宿主应用必须验证工具是否允许、调用者是否有权限、参数是否符合 schema，再由应用执行并把结果返回模型。不能把模型输出视为可信代码，也不能只依赖 JSON 格式有效就允许副作用操作。

### 24. Agent 的短期与长期记忆
短期工作记忆通常由当前对话和有限上下文窗口构成，承载任务即时状态；长期记忆可保存跨会话信息，并通过数据库、向量检索或知识图谱按需读取。长期记忆会带来过期、隐私、错误写入和越权读取风险，因此需要明确写入策略、数据保留期限、来源和用户权限。将历史信息存入向量库不等于模型拥有可靠、完整或永久记忆。

## 模块九：微调与 RAG 选型

### 25. RAG 与微调的适用场景
RAG 适合需要动态更新、可追溯或按权限检索的事实知识；微调更适合调整模型行为、任务格式、风格或领域模式。微调不能保证知识可准确编辑或来源可追溯，RAG 也不能保证模型一定正确使用检索内容。两者可以组合：先以检索提供当前证据，再以微调改善特定任务行为。方案选择应基于更新频率、数据敏感度、延迟、成本和评测结果。

### 26. LoRA 与 QLoRA
LoRA 冻结基础模型权重，并通过低秩矩阵表示权重更新，从而减少可训练参数和优化器状态。QLoRA 在量化基础权重的基础上进行低秩适配，以降低微调显存需求。两者降低资源门槛，但仍需考虑数据质量、目标模块、量化误差、训练稳定性和部署兼容性；参数高效不意味着训练不需要验证，也不保证任务效果一定提升。

## 模块十：推理优化与量化

### 27. PTQ、QAT 与低比特量化
量化用较低位宽表示权重或激活，以减少模型存储和计算开销。训练后量化（PTQ）在训练完成后执行，部署流程相对简单，但精度影响取决于模型、位宽和校准数据；量化感知训练（QAT）在训练过程中模拟量化误差，通常需要额外训练成本。GPTQ、AWQ 等是不同的权重量化方法，不能仅凭方法名称推断质量，应在目标任务与硬件上测量精度、延迟和吞吐。

### 28. PagedAttention 与连续批处理
PagedAttention 将 KV Cache 管理为固定大小的块，使请求的缓存不必按最大序列长度预留一整段连续显存，改善缓存分配灵活性并减少碎片。连续批处理允许已完成请求退出、较新的请求加入活动批次，提高推理服务资源利用率。实际吞吐收益取决于工作负载、上下文长度、并发数、硬件和调度策略，不应把某个实验中的固定倍数当成所有部署的保证。

## 模块十一：幻觉与模型评测

### 29. 大语言模型幻觉
幻觉通常指模型生成的内容缺乏事实依据、与提供的上下文矛盾或包含错误事实。自回归训练优化的是文本序列概率，不是对每个事实执行外部验证，因此语言流畅不能证明内容真实。降低风险可使用可追溯知识来源、检索证据、要求模型在证据不足时说明不确定性，并对高风险领域进行独立校验。检索到正确文档也不代表生成答案必然忠实。

### 30. LLM-as-a-Judge 与评测偏差
LLM-as-a-Judge 使用语言模型按评分规程比较或评价回答，可扩展评测规模，但可能存在位置偏差、冗长偏差、自我偏好和复杂推理题判分不准等问题。减轻偏差的方法包括随机交换候选顺序、使用明确的原子化评分标准、隐藏模型身份、加入人工抽检，并报告与人工标注的一致性。模型裁判分数适合作为辅助证据，不应取代人工审核和可复现的固定测试集。
